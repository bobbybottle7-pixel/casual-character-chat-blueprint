Characters

Not built yet — this is Milestone 3.

What this will do

Create AI characters with a name, personality, background, speaking style, goals, their relationship to you, their own memory and an optional picture. Characters will be saved as plain data, so they can be exported, shared and edited without touching any code.

The groundwork is already here: characters have their own place in storage, and the chat screen already sends a system prompt, which is what a character is made of.

Council

Not built yet — this is Milestone 4.

What this will do

Put one question to several different models, then have a final model read all their answers and write a combined one.

An honesty rule is built into the plan: if only one model is configured, Council will say plainly that it is running with one model. It will never fake a panel by asking a single model to play several parts.

Model Lab

Not built yet — this is Milestone 5.

What this will do

Send the same prompt to several models side by side and compare what comes back, with the time each one took, the tokens each one used and the cost where it is known.

It will show you the results and let you judge. It will not tell you which model is "best", because that depends on what you are doing.

Memory

Permanent memory: short facts sent with every message, on every model. ALLAI never writes anything here on its own — only what you type below.

The three kinds of memory

Permanent memory — the list above. Always sent. Only you put things in it.

Conversation history — the messages in a chat. Saved on this phone, sent with that chat only.

Temporary context — things that exist only while ALLAI is open, and are gone when you close it.
